# 企业经营研究工作台：UI 设计系统

## 产品布局

桌面应用采用三栏研究工作区：左侧管理研究项目，中间呈现项目证据与研究结果，右侧 Agent 始终与当前项目关联。设置与关于页面作为次级入口。报告和来源证据并列，方便用户核查结论依据。

## 视觉规则

- 保留 Folio 既有桌面框架与克制、紧凑的面板表达；不复制或冒称 Craft Agents 素材。
- 优先使用 `bg-background`、`bg-surface`、`bg-surface-muted`、`text-foreground`、`border-border` 等语义 token。
- 控件和卡片需键盘可操作，兼顾无障碍，并支持浅色与深色主题。
- Fixture 数据必须标记为说明性内容；搜索摘要和已打开的网页正文需要区分。
- 不使用股票行情隐喻、报价卡片、投资标签或金融仪表盘。

## 交互规则

- 切换项目时，中间区和右侧 Agent 同步更新作用域。
- Agent 提问创建关联当前项目的研究运行；追问保留父运行关系。
- 明确展示排队/运行/终态、动态决策、证据链接、错误和取消操作。
- 监控操作限定到当前项目；移除订阅后仍保留历史记录。
- 设置中保留模型配置、凭据状态、诊断、错误恢复和运行时重启。

# 企业经营研究工作台：产品与验收说明

## 产品定位

这是面向企业经营、战略与产品团队的 Windows 桌面研究工作台。研究项目是入口；Agent 根据用户问题和当前证据动态选择公开检索、打开已发现来源或结束研究；工作台保存决策轨迹、证据、报告、追问及主题监控。

保留 Folio 的 Electron / React 桌面框架、Pi Agent 运行时基础、会话体验和三栏布局。本仓库由 Folio 共同开发者继续维护；此项目不宣称采用 Craft Agents 源码。

## 主要流程

1. 创建研究项目，记录行业和 2–4 家研究对象。
2. 在右侧 Agent 提出问题；每个请求创建绑定项目的研究运行，追问记录父运行关系。
3. 中间区域展示运行状态、Agent 决策、工具动作、公开来源证据、报告、报告差异和主题监控。
4. 保存订阅后，应用运行时定期比较公开来源；达到变化门槛时创建绑定原项目的新运行。
5. 重启后从本地存储恢复项目、运行、事件、报告、订阅和监控状态。

## 数据边界与迁移

- 只采集可公开访问的信息；公开评论不是代表性客户调研。
- 不接入企业内网、客户研究系统或独立结构化企业数据源。
- 旧企业研究运行按主题归入项目。迁移需可重复执行、遇到目标记录时不覆盖。
- Pi 会话、研究运行、Agent 工具动作、证据和报告引用使用同一运行标识。
- 凭证保存在主进程安全凭证存储，不写入 renderer、诊断导出或日志。
- Windows 产品改名后继续使用旧的 userData 目录，避免旧研究和凭证失联。

## 明确不属于本产品的能力

不提供股票行情、证券上下文、投资组合、筛选、投资论点、券商连接、Longbridge、证券专属 Agent 问答或投资建议。Pi 扩展仅暴露本次企业研究所需的公开搜索和来源读取工具。

| 指标 | 当前固定验收口径 | 门槛 / 边界 |
| --- | --- | --- |
| 任务目录 | 6 个唯一任务 ID | 不等同 Folio 投资研究的 17 类 |
| 策略目录 | 3 个唯一策略 ID | 不等同 Folio 投资研究的 8 套 |
| 固定案例 | 24 个 fixture 案例 | 24/24 通过；0 失败、0 排除 |
| 运行/终态 | 案例预期产生 22 次运行；completed / partial / failed / cancelled 分开统计 | 未启动计为案例失败 |
| 正常完成 | 正常任务中 completed 且必需章节齐全并至少包含一个有效引证的案例数 / 正常案例总数 | fixture 6/6 |
| 预期结果 | 终态或监控应触发/不触发与标注一致的案例 / 全部案例 | fixture 24/24 |
| 工具选择 | 动作和参数均在标注允许集合内的检查点 / 全部工具决策检查点 | fixture 58/58；真实模型反事实决策单独验收 |
| 引证有效 / 事实覆盖 | 支持相关论断的有效引用 / 全部引用；具有效引用的事实论断 / 全部事实论断 | fixture 17/17、14/14 |
| 冲突 / 恢复 | 检出预期冲突案例 / 冲突案例；按预期重试、降级或明确失败案例 / 恢复案例 | fixture 各 3/3 |
| 自动触发 | 正确触发 / 所有触发；正确触发 / 应触发案例 | fixture 各 2/2；重复信号不得重复触发 |
| 运行耗时 | 确定性 fixture 从运行开始到终态；p50 算术中位数，p95 nearest-rank | 仅报告样本数和耗时，不作为线上性能承诺 |
| UI 闭环 | 项目→Agent 运行→证据/轨迹→报告→追问→重载恢复；监控运行保留项目归属 | Windows Electron 与打包版均通过 |

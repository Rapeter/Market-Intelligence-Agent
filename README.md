# Market Intelligence Agent

面向企业经营、战略和产品团队的桌面研究工作台。目标是让 Agent 根据公开信息和每一步获得的证据，动态决定下一步查什么，最终生成带来源、冲突与信息缺口的竞品和行业报告，并在应用运行时追踪新信息。

> 当前处于开发中。工作台的底层桌面与 Agent 能力来自 Folio 共同开发阶段的代码；本仓库正在增加独立的企业研究工作流。下方“计划能力”是设计目标，不代表已交付功能。

## 计划能力

- 公开信息研究：行业格局、竞品产品、公开价格与渠道、公开客户反馈信号、政策与技术风险、证据冲突核查。
- 动态 Agent 决策：基于当前证据选择下一项公开检索、打开已发现来源，或结束研究；运行过程保留可回放记录。
- 证据报告：区分搜索摘要与已读取网页内容，为事实性结论保留出处、反证和待核实信息。
- 新信息追踪：应用运行期间定时检查订阅主题；发现实质变化后重新研究并比较新旧报告。应用关闭期间不承诺后台监控。
- 目标评测规模：6 类企业研究任务、3 套策略、24 个可执行评测案例。只有实现并运行后，才会公布实际通过结果。

系统只使用公开可访问的信息。网页中抽取的日期、产品或公开价格会保留来源 URL 和原文片段；公开评论只作为可能有偏的反馈信号，不等同于代表性客户调研。首版不接入企业内网或独立的企业数据服务。

## 技术结构

```text
React 工作台
   │ typed IPC
Electron 主进程 ── 持久化、凭证、调度、公开检索
   │
业务研究 Runtime ── Agent 决策 → 工具调用 → 观察 → 报告
   │
Folio 既有 Pi Agent 运行时与桌面基础
```

## 本地运行

需要 Bun 和 Node.js。安装依赖并启动桌面开发模式：

```bash
bun install
bun run dev
```

项目功能、API 密钥设置与演示步骤会随可运行的研究流程一同补齐。实时检索需要公开搜索服务凭证；未配置时不能把示例材料当作实时结论。

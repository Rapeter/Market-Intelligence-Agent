# 企业经营研究工作台

这是一个面向企业经营、战略和产品团队的 Windows 桌面研究工作台。它以研究项目组织公开信息研究，通过动态 Agent 决策、证据与来源记录、报告、追问和信息变更监控形成可追溯流程。

完整的中文项目说明、验收指标、运行方式与实时凭证配置步骤见[主 README](README.md)。英文版本见[README.en.md](README.en.md)。

项目历史：我与 helsome 共同开发了 Folio。本仓库保留此前的提交历史和贡献记录；这里的企业经营研究工作流与产品体验作为个人仓库中的持续成果维护。Folio 原有投资研究功能及其评测数据不计为本项目新增成果。
